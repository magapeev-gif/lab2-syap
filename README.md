# Chronos Light

Игра на Python + pygame: лабиринт тёмен, стены двигаются, пока на них не падает свет
фонарика. Нужно дойти до зелёного выхода за отведённое время.

Лабораторная работа 1 - игровая механика. Лабораторная работа 2 - работа с файлами
(JSON-уровень, лог событий, таблица рекордов в CSV).

## Запуск

```
pip install pygame
python main.py
```

Нужен Python 3.12 или выше (в коде используется `match`).

Управление: **WASD** - движение, **мышь** - направление фонарика, **F1** - показать
тёмные стены (отладка), **R** - таблица рекордов (в меню), **ENTER** - старт и подтверждение.

## Структура проекта

| Файл | Назначение |
|---|---|
| `main.py` | главный цикл, состояния игры (меню, игра, победа/поражение, ввод имени, рекорды) |
| `level.py` | лабиринт и сдвиг невидимых стен |
| `player.py`, `light.py` | игрок и алгоритм конуса света |
| `ui.py` | отрисовка экранов |
| `constants.py` | настройки и пути к файлам |
| `storage.py` | **работа с файлами:** загрузка и валидация `level.json`, запись и чтение `records.csv` |
| `game_log.py` | **логирование** в `game_flight.log` |

## Файлы данных

| Файл | Формат | Кто создаёт | Назначение |
|---|---|---|---|
| `level.json` | JSON | вручную (лежит в репозитории) | описание уровня, читается при каждом старте игры |
| `game_flight.log` | текст | игра, автоматически | журнал событий с временными метками |
| `records.csv` | CSV (UTF-8) | игра, автоматически | результаты партий |

Все пути строятся от папки проекта (`pathlib`), поэтому не зависят от того, откуда запущена игра.

### level.json

```json
{
  "level": [
    "11111111111111111111",
    "10000000010000000001",
    "...(всего 15 строк по 20 символов)...",
    "11111111111111111111"
  ],
  "player_start": [1, 1],
  "exit": [18, 13],
  "time_limit": 90,
  "wall_shift_interval": 3.0
}
```

| Ключ | Обязателен | Описание |
|---|---|---|
| `level` | да | матрица 15 x 20: `1` - стена, `0` - пол. Строка из символов или список чисел |
| `player_start` | нет | клетка старта `[x, y]` (по умолчанию `[1, 1]`) |
| `exit` | нет | клетка выхода `[x, y]` (по умолчанию `[18, 13]`) |
| `time_limit` | нет | лимит времени, секунды (по умолчанию 90) |
| `wall_shift_interval` | нет | через сколько секунд в тени стена сдвигается (по умолчанию 3.0) |

**Валидация.** Перед игрой проверяется: корень - объект; есть ключ `level`; ровно 15 строк по
20 клеток, значения только 0/1; внешняя рамка состоит из стен; старт и выход - целые координаты
внутри поля на клетках-полу и не совпадают; выход достижим от старта (поиск в ширину);
`time_limit` и `wall_shift_interval` - положительные числа.

**Обработка ошибок.** Файл отсутствует (`FileNotFoundError`), повреждён (`JSONDecodeError`),
не в UTF-8 (`UnicodeDecodeError`), не прошёл проверку (`ValueError`) или недоступен (`OSError`):
игра не падает, использует встроенный уровень по умолчанию, показывает причину в меню и
пишет её в лог (уровень `ERROR`).

### game_flight.log

Одна строка - одно событие: `дата время | уровень | сообщение`.

```
2026-03-05 14:21:07 | INFO | Игра запущена
2026-03-05 14:21:07 | INFO | Уровень загружен из level.json
2026-03-05 14:21:09 | INFO | Новая игра: старт (1, 1), выход (18, 13), лимит 90 с
2026-03-05 14:21:10 | INFO | Шаг игрока: клетка (2, 1)
2026-03-05 14:21:58 | INFO | Победа: время 48.7 с, сдвигов стен 31
2026-03-05 14:22:03 | INFO | Рекорд сохранён: Иван, Победа, 48.7 с
```

Логируются: запуск и закрытие игры, загрузка уровня и её ошибки, старт партии, смена клетки
игроком, прерывание партии (ESC), переключение отладки (F1), победа и поражение, сохранение
рекорда, необработанные исключения (с трассировкой). Режим `LOG_LEVEL = "DEBUG"` в
`constants.py` дополнительно пишет каждый сдвиг стены.

### records.csv

```
Имя,Статус,"Время, с",Сдвигов стен,Дата
Иван,Победа,48.7,31,2026-03-05 14:21:58
Мария,Поражение,90.0,57,2026-03-05 14:25:10
```

Файл создаётся при первом сохранении (с заголовками), дальше строки дописываются в конец
(`open(..., "a")`). После партии игра запрашивает имя; пустое имя заменяется на «Аноним».
Таблица рекордов показывает 5 самых быстрых побед.

## Зачем JSON и CSV

- **JSON** - вложенная структура (матрица + координаты + числа), читается человеком и легко
  правится вручную.
- **CSV** - плоская таблица, дописывается строка за строкой без перечитывания файла,
  открывается в Excel.
